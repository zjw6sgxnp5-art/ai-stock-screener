# CF CF 工业（CF Industries Holdings, Inc.，标普500）— 个股分析

## 一、公司是做什么的
北美最大的氮肥（氨、尿素、硝酸铵溶液 UAN）生产商。用北美便宜的天然气生产氨，成本远低于欧洲和亚洲依赖进口天然气的竞争对手；正在路易斯安那 Blue Point 建设低碳氨工厂（与 JERA、三井合资）。
- 氨、尿素、UAN、硝酸铵等氮肥：主要卖给美国玉米种植户
- 工业用氮产品与柴油尾气处理液 DEF
- 低碳氨：Blue Point 合资项目，面向日本等能源转型市场

**竞争与护城河：** 北美低价天然气带来的结构性成本优势 + 美国中西部物流网络，护城河 3 分；但化肥价格是大宗商品。

## 五、为什么能买（看多理由）
1. 成本优势：北美便宜天然气
2. 股东回报极强：回购+分红约占市值 9%
3. 资产负债表健康：净负债/EBITDA 约 0.3 倍
4. 低碳氨是长期增长选项

**为什么现在不买 / 不急着买：**
- 2026 年盈利受益于全球化肥价格暴涨（中东局势），2027 年 EPS 预期 -24%

- Blue Point 项目资本开支大
- 美国天然气价格上涨会压缩成本优势

## 六、最大的担忧，以及是否在解决
**担忧：2026 年 CF 的利润被中东局势推高的全球化肥价格抬高，一旦局势缓和，氮肥价格和 EPS 都会回落，2027 年预期已 -24%。**
→ **部分缓解**：CF 在周期高位大量回购（约 9% 市值/年），每股价值在增厚；资产负债表强，下行时不会有财务风险。
