# BALL 波尔（Ball Corporation，标普500）— 个股分析

- 日期：2026-10-29（北京时间）｜价格为 2026-10-28 美股收盘/盘后（雅虎）
- **结论：逢低关注（21/30）**
- **账户规则：符合。**

## 一、公司是做什么的
全球最大的铝制饮料罐生产商。客户是可口可乐、百事、百威英博、能量饮料和气泡水品牌，按罐收费，原料铝价大多可以转嫁给客户。2024 年把航空航天业务卖给 BAE，现在是纯铝罐公司。
- 北美和中美饮料包装：最大板块
- 欧洲中东非洲饮料包装：增长较快
- 南美饮料包装：巴西为主，受汇率影响大
- 其他（铝制气雾罐、杯子）

**竞争与护城河：** 铝罐行业是寡头（Ball、皇冠 Crown、Ardagh），工厂靠近客户、规模化生产有成本优势；但对大客户议价能力有限，护城河 3 分。

## 五、为什么能买（看多理由）
1. 估值偏低：远期PE 约 13.9 倍，2021–2023 年年末 PE 22.7–36.3 倍（2024 年 4.2 倍含卖航天业务的一次性收益，不可比）
2. 盈利增长恢复：今年 EPS 预期 +12.5%，明年再 +12.5%，管理层承诺 10% 以上的可比 EPS 增长
3. 股东回报很高：2025 年回购 13.2 亿 + 分红 2.2 亿，约占市值 9%，在大量缩股
4. 铝罐替代塑料瓶和玻璃瓶是长期趋势，出货量 +4%

## 六、最大的担忧，以及是否在解决
**担忧：2022–2024 年收入连续 3 年下滑，叠加卖掉航天业务，市场怀疑铝罐需求见顶；股价 5 年跌了约 32%。**
→ **正在缓解**：2025 年收入恢复 +11.6%，2026 年出货量和 EPS 都在增长；但饮料消费疲软（尤其啤酒）的担忧仍在。

## 七、要认清的风险
- 财务：净负债/EBITDA 约 3.4 倍，回购部分靠借债，利率上升会侵蚀 EPS
- 经营：大客户集中、饮料消费疲软（啤酒销量下滑），影响中等
- 关税：美国铝关税抬高成本，转嫁有滞后
- 汇率：巴西、欧洲业务占比高
